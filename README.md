# ProjectCreation

The official ProjectCreation website — home of the ProjectCreation suite of tools.

## Pages

- **Home** — interactive network globe, product showcase, philosophy, newsletter
- **Projects** — overview of the full suite
- **Pricing** — subscription tiers
- **Account / Login / Signup** — Supabase-powered auth

## Commands

```bash
npm install
npm run dev        # local dev server
npm run build      # production build
```

## Tech

- Vite + React + TypeScript
- Supabase for auth
- Cloudflare for deployment and edge functions
- Interactive 3D network globe (drag, zoom)

Built in the ProjectCreation visual system: dark grid, cyan accents, square panels, monospace type.
