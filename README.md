# ProjectCreation

The official ProjectCreation website — a dark, technical landing page for the ProjectCreation suite of tools.

## Features

- Interactive rotating network globe (drag and zoom)
- Product cards for the full suite
- Philosophy and brand sections
- Newsletter signup
- Fully responsive (desktop and mobile)

## Commands

```bash
npm install
npm run dev
npm run build
```

## Live

[projectcreation.co](https://projectcreation.co) *(or wherever it's deployed)*
